# Dokumentasi Rumus Penilaian Skripsi

## 1. Nilai Bimbingan (Dari Pembimbing)

### 1.1. Nilai Rata-rata per Pembimbing
Setiap pembimbing (Pembimbing 1 dan Pembimbing 2) memberikan nilai berdasarkan 4 aspek:

**Rumus:**
```
Nilai Rata Pembimbing = (Kedisiplinan + Kreativitas + Penguasaan Materi + Kelengkapan Referensi) / 4
```

**Aspek Penilaian:**
- **Kedisiplinan** (0-100)
- **Kreativitas** (0-100)
- **Penguasaan Materi** (0-100)
- **Kelengkapan Referensi** (0-100)

**Contoh:**
- Pembimbing 1: Kedisiplinan=90, Kreativitas=85, Penguasaan Materi=88, Kelengkapan=87
- Nilai Rata P1 = (90 + 85 + 88 + 87) / 4 = **87.50**

- Pembimbing 2: Kedisiplinan=85, Kreativitas=80, Penguasaan Materi=82, Kelengkapan=83
- Nilai Rata P2 = (85 + 80 + 82 + 83) / 4 = **82.50**

### 1.2. Nilai Bimbingan Final
Nilai bimbingan final adalah rata-rata dari nilai pembimbing 1 dan pembimbing 2.

**Rumus:**
```
Nilai Bimbingan Final = (Nilai Rata P1 + Nilai Rata P2) / 2
```

**Contoh:**
- Nilai Rata P1 = 87.50
- Nilai Rata P2 = 82.50
- Nilai Bimbingan Final = (87.50 + 82.50) / 2 = **85.00**

**Catatan:** Jika hanya ada satu pembimbing yang memberikan nilai, maka nilai bimbingan final = nilai dari pembimbing tersebut.

## 2. Nilai Sidang (Dari Penguji)

### 2.1. Perhitungan N1, N2, N3, N4 per Penguji

Setiap penguji (Ketua Penguji, Anggota Penguji 1, Anggota Penguji 2) memberikan nilai berdasarkan 13 aspek yang dikelompokkan menjadi 4 kategori:

#### **N1 - Aspek Penulisan**
**Rumus:**
```
N1 = (Nilai Sistematika + Nilai Bahasa + Nilai Format) / 3
```

**Aspek:**
- **Nilai Sistematika** (0-100): Ketepatan Sistematika dan Konsistensi
- **Nilai Bahasa** (0-100): Ketepatan Bahasa yang digunakan
- **Nilai Format** (0-100): Ketepatan Format Penulisan

**Contoh:**
- Nilai Sistematika = 90
- Nilai Bahasa = 85
- Nilai Format = 88
- **N1 = (90 + 85 + 88) / 3 = 87.67**

#### **N2 - Aspek Penguasaan Materi**
**Rumus:**
```
N2 = (Nilai Penguasaan Isi + Nilai Penguasaan Tugas + Nilai Penguasaan Konsep) / 3
```

**Aspek:**
- **Nilai Penguasaan Isi** (0-100): Penguasaan Isi Materi Tugas Akhir
- **Nilai Penguasaan Tugas** (0-100): Penguasaan Isi Tugas Akhir
- **Nilai Penguasaan Konsep** (0-100): Penguasaan Konsep Perancangan

**Contoh:**
- Nilai Penguasaan Isi = 88
- Nilai Penguasaan Tugas = 90
- Nilai Penguasaan Konsep = 85
- **N2 = (88 + 90 + 85) / 3 = 87.67**

#### **N3 - Aspek Presentasi**
**Rumus:**
```
N3 = (Nilai Penampilan + Nilai Penggunaan Alat + Nilai Kesesuaian Waktu + Nilai Kejelasan Materi) / 4
```

**Aspek:**
- **Nilai Penampilan** (0-100)
- **Nilai Penggunaan Alat** (0-100): Penguasaan Penggunaan Alat
- **Nilai Kesesuaian Waktu** (0-100): Kesesuaian Penggunaan Waktu
- **Nilai Kejelasan Materi** (0-100): Kejelasan Mengungkapkan Materi

**Contoh:**
- Nilai Penampilan = 85
- Nilai Penggunaan Alat = 88
- Nilai Kesesuaian Waktu = 90
- Nilai Kejelasan Materi = 87
- **N3 = (85 + 88 + 90 + 87) / 4 = 87.50**

#### **N4 - Aspek Produk**
**Rumus:**
```
N4 = (Nilai Penguasaan Produk + Nilai Perancangan Produk) / 2
```

**Aspek:**
- **Nilai Penguasaan Produk** (0-100): Penguasaan Produk Tugas Akhir
- **Nilai Perancangan Produk** (0-100): Hasil Perancangan Produk Tugas Akhir

**Contoh:**
- Nilai Penguasaan Produk = 90
- Nilai Perancangan Produk = 88
- **N4 = (90 + 88) / 2 = 89.00**

### 2.2. Nilai Total per Penguji
**Rumus:**
```
Nilai Total Penguji = (N1 + N2 + N3 + N4) / 4
```

**Contoh:**
- N1 = 87.67
- N2 = 87.67
- N3 = 87.50
- N4 = 89.00
- **Nilai Total = (87.67 + 87.67 + 87.50 + 89.00) / 4 = 87.96**

### 2.3. Nilai Sidang Final
Nilai sidang final adalah rata-rata dari nilai total semua penguji (Ketua Penguji, Anggota Penguji 1, Anggota Penguji 2).

**Rumus:**
```
Nilai Sidang Final = (Nilai Total Ketua + Nilai Total Anggota 1 + Nilai Total Anggota 2) / 3
```

**Contoh:**
- Nilai Total Ketua Penguji = 87.96
- Nilai Total Anggota Penguji 1 = 88.50
- Nilai Total Anggota Penguji 2 = 88.00
- **Nilai Sidang Final = (87.96 + 88.50 + 88.00) / 3 = 88.15**

---

## 3. Nilai Akhir Skripsi

Nilai akhir skripsi dihitung dengan bobot:
- **40%** dari Nilai Bimbingan Final
- **60%** dari Nilai Sidang Final

**Rumus:**
```
Nilai Akhir Skripsi = (0.4 × Nilai Bimbingan Final) + (0.6 × Nilai Sidang Final)
```

**Contoh:**
- Nilai Bimbingan Final = 85.00
- Nilai Sidang Final = 88.15
- **Nilai Akhir Skripsi = (0.4 × 85.00) + (0.6 × 88.15) = 34.00 + 52.89 = 86.89**

---

## 4. Konversi ke Grade (Nilai Huruf)

**Rumus Konversi:**
```
Jika Nilai Akhir >= 81.9  → Grade = A
Jika Nilai Akhir >= 69.0  → Grade = B
Jika Nilai Akhir >= 60.0  → Grade = C
Jika Nilai Akhir >= 49.0  → Grade = D
Jika Nilai Akhir < 49.0   → Grade = E
```

**Contoh:**
- Nilai Akhir = 86.89 → **Grade = A**
- Nilai Akhir = 75.50 → **Grade = B**
- Nilai Akhir = 65.00 → **Grade = C**
- Nilai Akhir = 55.00 → **Grade = D**
- Nilai Akhir = 45.00 → **Grade = E**

---

## 5. Ringkasan Rumus

### Nilai Bimbingan
1. **Nilai Rata Pembimbing** = (Kedisiplinan + Kreativitas + Penguasaan Materi + Kelengkapan) / 4
2. **Nilai Bimbingan Final** = (Nilai Rata P1 + Nilai Rata P2) / 2

### Nilai Sidang
1. **N1** = (Sistematika + Bahasa + Format) / 3
2. **N2** = (Penguasaan Isi + Penguasaan Tugas + Penguasaan Konsep) / 3
3. **N3** = (Penampilan + Penggunaan Alat + Kesesuaian Waktu + Kejelasan Materi) / 4
4. **N4** = (Penguasaan Produk + Perancangan Produk) / 2
5. **Nilai Total Penguji** = (N1 + N2 + N3 + N4) / 4
6. **Nilai Sidang Final** = Rata-rata dari semua penguji

### Nilai Akhir
1. **Nilai Akhir Skripsi** = (0.4 × Nilai Bimbingan) + (0.6 × Nilai Sidang)
2. **Grade** = Konversi berdasarkan tabel di atas

**2. Nilai Sidang:**

- **Anggota Penguji 1:**
  - N1 = (88+87+89)/3 = **88.00**
  - N2 = (90+88+87)/3 = **88.33**
  - N3 = (87+89+88+90)/4 = **88.50**
  - N4 = (89+90)/2 = **89.50**
  - Nilai Total = (88.00+88.33+88.50+89.50)/4 = **88.58**

- **Anggota Penguji 2:**
  - N1 = (87+86+88)/3 = **87.00**
  - N2 = (87+89+86)/3 = **87.33**
  - N3 = (86+87+89+88)/4 = **87.50**
  - N4 = (88+87)/2 = **87.50**
  - Nilai Total = (87.00+87.33+87.50+87.50)/4 = **87.33**

- **Nilai Sidang Final** = (87.96+88.58+87.33)/3 = **87.96**

**3. Nilai Akhir Skripsi:**
- Nilai Akhir = (0.4 × 85.00) + (0.6 × 87.96) = 34.00 + 52.78 = **86.78**

**4. Grade:**
